# Yasmin Diniz - Landing Page

Cópia exata e fiel da landing page original de **Yasmin Diniz** ([yasmin-diniz-landing-l5e4.bolt.host](https://yasmin-diniz-landing-l5e4.bolt.host/)).

Desenvolvido com **React 18**, **TypeScript**, **Tailwind CSS** e **Vite**, reproduzindo integralmente a arquitetura visual, tipográfica, responsiva e interativa original.

## 🎨 Características Implementadas

- **Tipografia e Estilo**:
  - Títulos elegantes com **Cormorant Garamond**.
  - Texto e interface com **Manrope**.
  - Paleta completa de cores da identidade visual (`paper`, `ink`, `cream`, `olive`, `terracotta`, `foliage`, `mustard`, `rose`, `sky`).
- **Seções e Conteúdo 100% Fiéis**:
  - **Header fixo responsivo** com efeito blur ao rolar e menu mobile animado.
  - **Hero Section**: Apresentação de impacto, botões de ação e composição geométrica artística.
  - **Sobre a Artista**: Biografia autoral, manifesto e citação de assinatura.
  - **Portfólio Interativo**: Filtro dinâmico por categoria (Todos, Botânicos, Infantil, Personagens, Abstrato, Comercial), layout em colunas/masonry com efeitos de hover.
  - **Modal Lightbox de Obras**: Visualização em tela cheia com navegação por teclado (Escape, Setas), suporte a swipe/touch e contador de itens.
  - **O Que Podemos Criar**: Cards de serviços com link direto de atendimento.
  - **Como Funciona**: Timeline conectada em 4 etapas detalhadas do processo criativo.
  - **Faixa de Manifesto / Frase Marcante**: Com formas orgânicas SVG decorativas.
  - **Orçamento / Contato**: Card central com chamada direta para o WhatsApp (`https://contate.me/comamorayra`).
  - **Instagram**: Feed de inspiração com link para o perfil (`@_yasmindiniz`).
  - **Rodapé Completo**: Links de navegação, contatos e direitos autorais.
- **Interatividade & Animações**:
  - `Reveal`: Animação suave com `IntersectionObserver` para revelação gradual das seções.
  - Transições fluidas de hover nos botões e cards de arte.

## 🚀 Como Executar

### 1. Instalar dependências
```bash
npm install
```

### 2. Iniciar servidor de desenvolvimento
```bash
npm run dev
```

### 3. Gerar build de produção
```bash
npm run build
```

### 4. Testar preview do build
```bash
npm run preview
```
